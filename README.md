# Daniels Health – Supplier Shipping Label (QMS-016 Rev B)

Single-page label generator for suppliers. Generates the 6 × 4 in supplier shipping label with two Data Matrix codes
(ORDER # = PO number, PRODUCT DETAILS = `Item%Qty%Lot`). Barcodes are generated in the browser; no external service.

- Live page: GitHub Pages (see repository settings)
- `index.html` is fully self-contained and also works offline when downloaded.
- Access is gated with a shared supplier username/password (client-side deterrent, not a security control).

Built from `QMS-016 Supplier Shipping Label Template Rev B`; guidelines summarised from `SOP-029 Product Labelling Rev B`.
